Roblox Asset Uploader

Demostración del Assets API de Open Cloud: sube un archivo a tu propia cuenta de Roblox y recibe su assetId.

Para Model, selecciona un archivo .rbxm o .rbxmx. Los demás tipos requieren formatos compatibles con Roblox.

Tu API key se envía solo a Roblox para esta subida. Este sitio no la guarda ni la registra. Crea una key solo con permiso de assets y bórrala al terminar.
